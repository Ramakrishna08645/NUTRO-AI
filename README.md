# NUTRO AI — Minimal visual prototype

This version intentionally contains only:
- NUTRO AI name
- Animated emerald orb
- Short tagline

The microphone, Tamil, speaker, and chat controls have been removed.

This is a visual prototype only. It is not connected to an AI model, voice service, internet research, memory, or phone controls.

## Open in Acode
1. Extract this ZIP.
2. In Acode, open the extracted folder.
3. Open `index.html`.
4. Tap the Preview (▶) button.

Do not overwrite your existing project until you have checked this version.
